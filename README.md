## 📌 About VEGZ

VEGZ is a farm-to-business vegetable supply platform in Karnataka.

👉 We connect **farmers directly** with:
- Hotels 🏨  
- Restaurants 🍽️  
- Tiffin centers 🍱  
- Vegetable shops 🛒  
- Bulk buyers 🏢  

❌ No middlemen  
✅ Fair prices  
🚚 Fast delivery  

---

## 🌱 Features

- 🥦 Fresh vegetables directly from farmers  
- 📦 5kg & 10kg packaging  
- 🚚 Daily delivery system  
- 💰 Instant payment to farmers  
- 🌐 Kannada + English support  
- 📍 Serving North Karnataka (Hubli, Dharwad, Gadag, Mundargi, etc.)
